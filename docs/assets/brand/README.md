# AngysGuard brand assets

See [`docs/BRAND_GUIDE.md`](../../BRAND_GUIDE.md) for product category, logo meaning, color rules, references and usage guidance.

This folder contains the canonical AngysGuard identity assets used by the repository, future desktop/mobile apps and product presentation.

## Primary files

- `angysguard-mark.svg` — scalable transparent logo mark.
- `angysguard-app-icon.svg` — square app icon source.
- `angysguard-mark-monochrome.svg` — single-color/symbolic version.
- `angysguard-wordmark-dark.svg` — horizontal wordmark for dark surfaces.
- `angysguard-wordmark-light.svg` — horizontal wordmark for light surfaces.
- `angysguard-readme-hero.svg` — GitHub README hero.
- `angysguard-social-preview.png` — 1280×640 repository/social preview.
- `angysguard-brand-assets-overview.png` — internal visual inventory.
- `reference/angysguard-brand-board.png` — generated concept/reference board.

## Icon exports

`icons/` contains PNG exports at 16, 20, 24, 32, 48, 64, 96, 128, 180, 192, 256, 512 and 1024 pixels, plus a multi-size `favicon.ico` and monochrome 512px variants.

Treat the SVG sources as canonical for future regeneration. Do not repeatedly rescale a tiny raster icon to make new platform assets.
